# Copilot instructions

[`AGENTS.md`](https://ehrlinger.github.io/AGENTS.md) at the repository
root is the operational contract for this repository and applies in full
to code review and to any change you propose. Read it first.

The rule most relevant to review: this package is not headed to CRAN,
and it is held to the CRAN standard anyway. Flag anything the [CRAN
Cookbook](https://contributor.r-project.org/cran-cookbook/) or
`R CMD check --as-cran` would flag, and do not discount a finding
because the package is internal.
