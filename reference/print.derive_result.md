# Print a derived dataset result without patient values

Print a derived dataset result without patient values

## Usage

``` r
# S3 method for class 'derive_result'
print(x, ...)
```

## Arguments

- x:

  A `derive_result` from
  [`derive_vars()`](https://ehrlinger.github.io/hvtiRdatabuild/reference/derive_vars.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
