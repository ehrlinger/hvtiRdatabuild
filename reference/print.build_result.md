# Print a built dataset result without patient values

Print a built dataset result without patient values

## Usage

``` r
# S3 method for class 'build_result'
print(x, ...)
```

## Arguments

- x:

  A `build_result` from
  [`build_dataset()`](https://ehrlinger.github.io/hvtiRdatabuild/reference/build_dataset.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
